# GeoGuardian 🐄🌱

**GeoGuardian** is a virtual pasture and animal management tool designed to help farmers control and monitor their livestock within designated zones. Inspired by *Halter*, this project focuses on simulating core features in a simplified and achievable scope — allowing users to manage animals and pastures directly through a user-friendly web interface.

This project is part of my learning journey to improve my web development skills and demonstrate my ability to build interactive, map-based applications.

---

## 🌟 Features

* 🗺️ **Pasture Management**

  * Add new pastures
  * Edit existing pasture shapes
  * Delete pastures

* 🐄 **Animal Management**

  * Add new animals
  * Relocate animals within zones
  * Delete animals

* 🔄 **Simulation Mode**
  Visual simulation of how animals behave within virtual boundaries, showing potential real-world applications.

---

## 🚀 Tech Stack

| Layer      | Technology                                        |
| ---------- | ------------------------------------------------- |
| Front End  | React.js                                          |
| Back End   | Node.js                                           |
| API        | HERE Maps API                                     |
| Data Store | JSON file (temporary; AWS planned for the future) |

> ⚠️ Note: Data is currently hardcoded using a JSON file. The original plan was to use AWS, but to meet my self-imposed deadline and focus on delivery, I chose to keep it local. I plan to learn and implement AWS in a future version.

## 🎯 Purpose

This project is a focused version of a more complex system like *Halter*. While Halter offers a wide range of advanced features, **GeoGuardian** aims to keep things simple, clean, and within scope — showcasing my current capabilities while setting the foundation for future growth.
